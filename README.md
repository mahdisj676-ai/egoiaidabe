# ✦ EGO / DABE ✦
**egoiaidabe** · دستیار شخصی هوشمند روی سرور لینوکس شما · Personal AI Butler

</div>

یک ایجنت هوش مصنوعی که روی سرور شما آنلاین می‌ماند و مثل یک خدمتکار انسانی کار انجام می‌دهد:
دستور اجرا می‌کند، فایل مدیریت می‌کند، در اینترنت جستجو می‌کند، یادآوری و پیام خودکار می‌فرستد،
ویس می‌گیرد و ویس می‌دهد (فارسی و انگلیسی) و از طریق **ربات تلگرام** و **پنل وب** کنترل می‌شود.
**برای هر کار از شما تایید می‌گیرد** (دکمه ✅ / ❌).

## ⚡ نصب با یک دستور (Ubuntu 22/24)

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/mahdisj676-ai/egoiaidabe/main/install.sh)
```

بعد از نصب، منوی طلایی باز می‌شود. هر وقت خواستید دوباره باز کنید فقط بنویسید: `dabe`

## 🧭 راه‌اندازی (۱۰ مرحله)

در منو حرف **S** (Quick Setup) را بزنید. هر بار یک مقدار را پیست می‌کنید و Enter می‌زنید:

1. کلید **Gemini** (رایگان) – `aistudio.google.com/apikey`
2. کلید **Groq** (رایگان، برای فهمیدن ویس؛ اختیاری)
3. کلید **OpenRouter** (جایگزین؛ اختیاری)
4. **توکن ربات تلگرام** – از @BotFather
5. **API ID و hash تلگرام** (اختیاری، برای پیام دادن به بقیه) – `my.telegram.org`
6. **رمز پنل وب**
7. **دامنه‌ی پنل** (اختیاری)
8. **منطقه زمانی**
9. **شروع سرویس**
10. **اتصال به اکانت شما** – به ربات می‌نویسید `/start کد`

برای رد کردن مرحله‌های اختیاری فقط Enter بزنید.

## 🌐 پنل وب با دامنه‌ی خودتان

1. در تنظیمات DNS دامنه یک **A record** بسازید که به IP سرور اشاره کند (IP را منو نشان می‌دهد).
2. اگر از Cloudflare استفاده می‌کنید، ابر را **خاکستری (DNS only)** کنید.
3. چند دقیقه صبر کنید، بعد در منو → **5** → **2** دامنه را وارد کنید.
4. خودکار **Caddy** نصب می‌شود و **HTTPS** (گواهی رایگان) برایتان می‌گیرد.
5. بعد از آن پنل روی `https://دامنه‌ی-شما` باز می‌شود و با رمز پنل وارد می‌شوید.

گزینه‌های دیگر در منو → 5: باز کردن روی `IP:پورت` (بدون رمزنگاری، پیشنهاد نمی‌شود) و برگرداندن پنل به حالت خصوصی.

## 🔥 قابلیت‌ها

| | |
|---|---|
| 🔗 **لینک ریلز/ویدیو** | لینک اینستاگرام، یوتیوب، تیک‌تاک، پینترست، X، فیسبوک، ساندکلود… بفرستید → **خود ویدیو + آهنگش (mp3)**؛ اسم آهنگ هم اگر پیدا شود می‌گوید |
| 🖼 **دیدن عکس** | عکس بفرستید، می‌بیند، می‌خواند و توضیح می‌دهد |
| 🎬 **دیدن ویدیو** | ویدیو یا لینکش را بدهید؛ فریم‌ها را می‌بیند و صدایش را می‌شنود |
| 🎨 **ساخت عکس** | «یه عکس از … بکش» (رایگان) |
| 🎤 **ویس** | ویس می‌فهمد؛ هر وقت بگویید با ویس جواب می‌دهد (فارسی/انگلیسی) |
| 💻 **سرور** | اجرای دستور، فایل، جستجوی اینترنت، یادآوری و پیام خودکار |
| 👤 **اکانت تلگرام شما** | لیست چت‌ها، خواندن پیام‌ها، فرستادن متن/ویس/فایل به هر کس |
| 🧠 **حافظه** | چیزهایی که بگویید «یادت باشه» را همیشه یادش می‌ماند |

مثال‌ها:
- فقط لینک ریلز را بفرستید ← ویدیو + mp3
- لینک + «آهنگش رو بده» ← فقط mp3 · لینک + «فقط ویدیو» ← فقط ویدیو
- «این ویدیو درباره چیه؟» + لینک ← تماشا می‌کند و جواب می‌دهد
- «به @ali یه ویس بده که فردا میام» · «آخرین پیام‌های گروه X رو بخون»
- «فردا ساعت ۸ یادم بنداز» · «هر روز ساعت ۹ صبح‌بخیر بفرست»

> لینک ویدیو که مستقیم بفرستید، بدون پرسیدن تایید دانلود می‌شود (چون خودتان خواسته‌اید). بقیه‌ی کارها طبق «حالت تایید» است.

### 🍪 اگر اینستاگرام لینک را نداد
اینستاگرام گاهی لاگین می‌خواهد. با مرورگر کامپیوتر (یا Kiwi/Firefox موبایل) وارد یک اکانت **فرعی** شوید، با افزونه‌ی «Get cookies.txt LOCALLY» فایل `cookies.txt` را بگیرید و همان فایل را به ربات بفرستید. (راهنما داخل ربات: `/cookies`)

### 📏 محدودیت‌ها
- ربات تلگرام فقط تا ۵۰ مگابایت می‌تواند بفرستد؛ ویدیوهای بزرگ‌تر خودکار فشرده می‌شوند.
- ویدیویی که **شما** به ربات می‌فرستید باید زیر ۲۰ مگابایت باشد (محدودیت تلگرام)؛ برای بزرگ‌تر، لینکش را بدهید.
- سایت‌ها مدام تغییر می‌کنند؛ ابزار دانلود (yt-dlp) هر روز خودکار آپدیت می‌شود.
- ساخت عکس و مدل‌های رایگان سقف دارند و ممکن است گاهی کند یا محدود شوند.

## 🩺 مشکل دارید؟ Doctor
در منو **D** را بزنید: همه‌چیز را چک می‌کند (پکیج‌ها، ffmpeg، کلیدها، توکن، سرویس، آخرین خطاها) و می‌گوید دقیقاً چه چیزی خراب است و آن را درست می‌کند.

## 🔒 امنیت

- فقط **مالک** (کسی که کد اتصال را فرستاده) می‌تواند به ربات دستور بدهد.
- حالت پیش‌فرض: **برای همه‌چیز تایید می‌گیرد** (منو → 6 برای تغییر).
- ربات دستورها را با دسترسی `root` اجرا می‌کند؛ هر تایید را با دقت بخوانید.
- رمز پنل قوی بگذارید؛ بعد از ۸ بار رمز اشتباه، ورود ۵ دقیقه قفل می‌شود.
- کلیدها در `/opt/dabe/data/config.json` با دسترسی ۶۰۰ ذخیره می‌شوند و داخل گیت‌هاب نمی‌روند.

## 🔄 آپدیت / حذف
منو → **U** آپدیت · منو → **X** حذف

## 🛠 عیب‌یابی
- ربات جواب نمی‌دهد → منو → **9** (لاگ زنده) را ببینید.
- HTTPS باز نمی‌شود → A record را چک کنید و مطمئن شوید پورت‌های 80 و 443 در فایروال/پنل سرور باز هستند.
- خطای 429 → سقف رایگان تمام شده؛ چند دقیقه صبر کنید یا کلید OpenRouter/Groq اضافه کنید؛ ایجنت خودش به بعدی می‌رود.
- نام مدل در منو → 6 → 4 قابل تغییر است (مدل‌های رایگان ممکن است تغییر کنند).
